Code and data availability

SARIMAX.jl is open-source software released under the MIT licence and developed publicly at
https://github.com/LAMPSPUC/Sarimax.jl. The release archived for this article [tag
ijf-2026-v1; software DOI 10.5281/zenodo.XXXXXXX] contains the package source (version
1.0.0), the scripts and configuration files of the experiments, and a containerized
computational environment (Julia, R, Python and the optimization solvers, with all versions
pinned) [published as ghcr.io/lampspuc/sarimax-ijf-replication@sha256:...]. A single command
(./reproduce.sh) verifies the environment and the archived inputs, runs small reference
computations, regenerates the tables from the archived per-series results and compares the
values reported in this article with them; separate commands re-run the experiments from the
original data.

The archived experimental results (per-series forecasts, accuracy metrics and solver
outcomes, and the scripts that produced them) are available at [data DOI
10.5281/zenodo.YYYYYYY]. [Tables 2-6 and S8-S10 and Figures 2 and 3 are regenerated from these
records.] Several experiments were run with development revisions of the package that
preceded the release; the replication materials record the revision and configuration of each
result. Re-execution of the full M4 campaigns, which requires several hundred CPU-hours, is
supported but was not repeated for this archive. The M4 competition data are not
redistributed; they are obtained from the organisers' repository
(https://github.com/Mcompetitions/M4-methods) at a fixed revision and verified by checksum.
